# 🦷 FormularioApp - Reserva de Cita Dental

Aplicación móvil desarrollada con **React Native + Expo** que permite a los pacientes agendar una cita en una clínica dental. El formulario incluye validaciones lógicas e interactivas en tiempo real, manejo de estados con `useState` y una interfaz adaptada a un estándar móvil limpio.

---

## 📋 Descripción del Proyecto

Este proyecto fue desarrollado como parte de la evaluación del curso **Desarrollo de Aplicaciones Móviles (DAM)**. Consiste en un formulario funcional de reserva de citas que:

- Captura datos del paciente (Nombre, Correo, Fecha y Motivo).
- Valida cada campo de forma lógica y en tiempo real.
- Muestra mensajes claros de error y éxito al usuario.
- Presenta una interfaz visual adaptada a un consultorio dental.

---

## 🎯 Campos del Formulario

| Campo | Descripción | Validación |
|-------|-------------|------------|
| **Nombre** | Nombre completo del paciente | Solo letras y espacios, mínimo 3 caracteres |
| **Correo** | Correo electrónico de contacto | Formato válido (ejemplo@correo.com) |
| **Fecha** | Fecha de la cita | Formato DD/MM/AAAA |
| **Motivo** | Razón de la consulta | Mínimo 10 caracteres |
